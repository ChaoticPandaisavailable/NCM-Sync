# NCM Sync 1.3.3

## 新功能

- **下载并发数可调**：设置页新增 1-8 路下载并发选择，可实现更快的下载速度。

## 修复

- **缺失封面和标签**：所有歌曲现在都会嵌入专辑封面与其它元数据。已下载歌曲在下次同步时自动回填封面。
- **单曲下载失败不再阻塞整个同步**：失败曲目自动跳过并继续下载其余歌曲，失败曲目保留待同步状态，下次同步自动重试。高品质音源不可用时会尝试音质降级回退。
- **速度优化**：优化了下载管线，音频下载完成后立即可用，不等待封面。封面在后台补齐。

## 安装与校验

下载 `NCMSync-1.3.3-Setup.exe` 与 `SHA256SUMS.txt` 后，先核对 SHA-256 再运行安装程序。

此安装包未进行商业代码签名，Windows SmartScreen 可能提示"无法识别的应用"。请只从本仓库 Release 页面下载。
