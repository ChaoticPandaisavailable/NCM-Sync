# NCM Sync 1.3.2

## 修复

- 当歌曲从在线歌单移除并同步删除，或其所属本地歌单被删除后，若该歌曲不再属于任何本地歌单，自动删除 `songs/` 中的实体文件和对应本地索引。
- 仍被其他本地歌单使用的共享歌曲实体会保留，避免误删。

## 许可证

源代码采用 GNU GPL v3.0（GPL-3.0-only）。

## 安装与校验

下载 `NCMSync-1.3.2-Setup.exe` 与 `SHA256SUMS.txt` 后，先核对 SHA-256 再运行安装程序。

此安装包未进行商业代码签名，Windows SmartScreen 可能提示“无法识别的应用”。请只从本仓库 Release 页面下载。
