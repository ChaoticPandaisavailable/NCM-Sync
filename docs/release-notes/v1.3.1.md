# NCM Sync 1.3.1

首个面向公众发布的 Windows 版本。

## 主要功能

- 创建与收藏歌单的完整分页读取，包括数千首歌曲的超大歌单。
- 增量扫描、一键同步、自动扫描和实时同步。
- 默认 4 路受控并发下载，支持暂停、继续、取消和逐歌单进度。
- 自动发现音乐库中与在线歌单对应的现有文件夹。
- NTFS 硬链接实体库，减少重复歌曲占用。
- 内置 NCM 流式转换，无需额外工具。
- 歌单暂停、离线重定向、在线/本地重命名处理和音乐库迁移。

## 安全与隐私

- 无遥测、广告或 NCM Sync 云端服务。
- Cookie 和用户数据仅保存在本地音乐库。
- Electron 主窗口启用沙箱与上下文隔离。
- 本地 API 拒绝非应用来源的写操作。

## 安装与校验

下载 `NCMSync-1.3.1-Setup.exe` 和 `SHA256SUMS.txt`，核对 SHA-256 后运行安装程序。

此安装包未进行商业代码签名，Windows SmartScreen 可能提示“无法识别的应用”。请只从本仓库 Release 页面下载。
